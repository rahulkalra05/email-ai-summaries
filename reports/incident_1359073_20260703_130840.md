# Operational Incident Investigation Report

## Incident Number
Incident# 1359073

## Reported Issue Summary
The Blackboard technical support team reported that a VIP UPN Laureate student is experiencing connection and assignment launch issues via the Blackboard application. Specifically, the student is unable to launch assignments associated with the Cambridge One (C1) platform, despite having previously completed a few activities in Unit 11. 

## Initial Assessment
Based on the current incident details, the affected components, products, and integrations include:
*   **Products & Platforms:** Cambridge One (C1), Blackboard Learning Management System (LMS), and Cambridge One LTI (Integration Gateway).
*   **Affected Components:** LMS configuration settings, student launch authentication tokens, and potentially back-end assessment player databases (such as Metrica or Litmus) that handle assignment states and progress tracking.

## Common Patterns Identified
*   **Launch Failure & Redirection Loops:** Across historical incidents (Ticket 1100066, Ticket 1083629, Ticket 1044716), students attempting to launch a Progress Test or assignment are redirected back to the launch screen or experience a loop because the launch state is blocked.
*   **State Synchronization Failures:** A recurring technical pattern involves a mismatch of attempt states between Cambridge One and external assessment systems (Metrica / Litmus). If a student has partial/completed records on one side but not the other, launch errors occur.
*   **Missing Score Payloads:** Problems often trace back to a failure in the submission/score-pushing workflow where the platform registers "In progress" or "in-complete" states without matching score payloads (Ticket 1044716, Ticket 1013019, Ticket 1313776).

## Root Cause Analysis

### Confirmed causes
*   **No Platform-Wide Outage:** It is confirmed that the Cambridge One platform and content are working correctly. Test launches with a test user succeeded, and the affected student previously completed activities in Unit 11.

### Suspected causes
*   **LMS Configuration Issue:** There may be an LTI or configuration mismatch at the user's specific institution/Blackboard end, preventing proper handshakes during current launch attempts.
*   **State Synchronization Mismatch:** The student may have an incomplete activity state or a locked session token inside Metrica/Litmus that prevents a clean launch, similar to Ticket 1083629 and Ticket 1044716.

### Missing evidence
*   **Student Logs:** The technical support team has requested student logs from the integration end to confirm the exact redirect URLs and error codes.
*   **LTI / Integration Gateway (`ltigw`) Logs:** Reviewing the `ltigw` logs is required to check if Blackboard is successfully transmitting the launch parameters and if any authentication/session errors exist.
*   **Metrica/Litmus State Verification:** Confirmation is needed from backend teams to check the current attempt state and see if any partial score payloads or submission blocks exist for this student.

If the logs reveal a state mismatch (e.g., the student has a stuck attempt status of "In progress" or "in-complete" in C1, but completed in the backend assessment engine), the recommended path is to have the engineering team perform a manual score sync or reset the attempt state via the established support procedures (such as COS-1346 or COS-1064), as resolved in Ticket 1083629 and Ticket 1013019.
