# Incident Investigation Report: 1359073

## Reported Issue Summary
The incident involves connection issues between VIP UPN Laureate [C1] and Blackboard, resulting in launch/redirect loops when users attempt to open progress tests on the ELT platform.

## Affected Systems
Cambridge One, Blackboard (LTI), Metrica Assessment Engine

## Common Patterns Identified
* Launch/Redirect loop when attempting to open progress tests
* Assignment status stuck in "In progress" or "Completed" incorrectly
* State synchronization mismatch between Cambridge One and Metrica
* Missing score payload preventing successful LTI launch

## Root Cause Analysis
- **Confirmed:** Backend data synchronization failures between Metrica and Cambridge One, as well as incorrect attempt states recorded in Metrica blocking new launches.
- **Suspected:** Multi-tab launch interference, asynchronous communication failure during score transmission, and intermittent API errors in Azure components.
- **Missing evidence:** Specific student UPNs/Emails and the corresponding attempt logs from the Metrica platform to compare against Cambridge One audit trails.

## Recommended Next Steps
1. Extract user logs from Cambridge One and verify submission status/timestamp (Source ticket: 1058626).
2. Query Metrica backend for the specific Test ID status to identify "Completed" vs "In-complete" mismatch (Source ticket: 1083629).
3. If state mismatch is confirmed, manually push the score payload or reset the attempt state (Source ticket: 1013019).

## Recommended Resolution
Identify the state mismatch via log correlation between Cambridge One and Metrica. Once the synchronization error is identified, trigger a manual score push or reset the test attempt in the Metrica platform.

## Confidence Level
**High**
Historical data across multiple tickets (1083629, 1058626, 1013019) consistently points to Metrica-to-Cambridge One synchronization issues as the primary driver for LTI launch failure/redirect loops.
