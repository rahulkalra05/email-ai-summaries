## Common Patterns Identified
* **Dashboard Display Discrepancies:** A recurring theme across Cambridge One (C1) where backend entitlement records in PEAS/Gigya are active (valid until 2026 in this case), but the frontend UI rendering components (such as icons, status text, or warnings) misrepresent the state or fail to load proper metadata (e.g., Ticket 1172157, Ticket 1191931, Ticket 341414).
* **Role Inconsistencies / Configuration Clashes:** Inconsistencies between user roles and account attributes (e.g., a student account carrying a `free_trialProductID` in Gigya, which is typically configured for teacher roles in PEAS) can cause unexpected UI rendering behaviors.
* **Component-Level UI Bugs:** Builder configurations and UI components frequently fail to propagate text descriptors dynamically based on individual entitlements.

## Root Cause Analysis

* **Confirmed causes:**
  * The Builder tool shows that components are visible and published, but the specific localization/description text string associated with the yellow warning icon is not rendering in the student's dashboard.
* **Suspected causes:**
  * **Role and Metadata Conflict:** The Gigya record containing `free_trialProductID` under `eduelt` for this student may be triggering a UI validation rule intended for teachers or trial accounts, rendering the yellow icon without its standard description.
  * **API/UI Desynchronisation:** Similar to COS-1774 and NEMO-20159, a synchronization failure between the PEAS database (which lists a 2026 expiration) and the C1 UI is causing the dashboard to prematurely flag the product with an expiration warning icon without loading the appropriate warning string.
* **Missing evidence:**
  * API response payloads from the C1 API for this specific UID to confirm if the warning message string is being returned in the JSON payload.
  * Confirmation from the Green Team / Compass Team on whether the yellow icon is hardcoded to specific role logic.
